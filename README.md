# 火星時計 — Mars Sol Clock

協定火星時（MTC）と通算ソル（MSD）の時計、火星の地図、火星探査機の一覧を
ひとつにまとめた Web アプリです。**オフラインで動きます。**

iPhone の Safari で開き、共有メニューから「ホーム画面に追加」すると、
アイコンから直接、通信なしで起動できます。

版: `2026-08-29 #56533d`

## できること

- **時計** — 協定火星時を秒まで表示。通算ソル（1873年12月29日を第0ソルとする通算日数）、
  着陸地点10か所の地方太陽時とミッションソル、火星年・季節・太陽黄経・均時差
- **地図** — 球体と平面を切り替え。IAU 承認の地名85件をタップで解説。
  暗い面はいまこの瞬間の火星の夜、光点は太陽の直下点
- **探査機** — 1964年のマリナー4号から2028年打ち上げ予定まで30ミッション。
  現役ローバーは現在のソル番号をリアルタイム表示

## 計算方法

火星の時刻は NASA ゴダード宇宙科学研究所の **Mars24 アルゴリズム**
（Allison & McEwen 2000, *Planet. Space Sci.* 48, 215-235）の実装です。

```
MSD = (JD_TT − 2451549.5) / 1.0274912517 + 44796.0 − 0.0009626
MTC = (24 × MSD) mod 24
LMST = (MTC + 東経 / 15) mod 24
```

除数 **1.0274912517** が「火星の1日は地球の1日の何倍か」です。1秒の長さは地球と同じで、
1ソル＝24時間39分35.244秒。この時計は地球の時計より約 2.7% ゆっくり進みます。

### 検証

推測ではなく、NASA が公開している実データと照合しています。

| 検証項目 | NASA の値 | この実装 |
|---|---|---|
| Mars24 の MSD 定義値（2000-01-06 00:00 UTC） | 44796.0 | 44795.99976 |
| パーサヴィアランス生画像メタデータ（2026-08-27 18:52:38 UTC 撮影） | `Sol-01962M15:32:14` | Sol 1962 / LMST 15:32:21 |
| 火星年 MY24 / MY36 / MY37 / MY38 の開始 | 1998-07-14 / 2021-02-07 / 2022-12-26 / 2024-11-12 | 同左 |

## 出典

すべて NASA / ESA / JAXA / ISRO / CNSA / UAE の公式資料に基づいています。
推測値は含まれていません。詳細はアプリ内の「資料」タブにあります。

| 内容 | 出典 |
|---|---|
| 火星時刻アルゴリズム | NASA GISS Mars24 |
| 着陸機の座標とソル番号 | NASA GISS Mars24 “Mars Landers” |
| 地名・座標・直径・命名由来 | USGS / IAU Gazetteer of Planetary Nomenclature |
| 全球地図 | NASA Ames / USGS「Mars Viking MDIM 2.1 Colorized Global Mosaic」 |
| 時計の背景写真 | NASA/JPL-Caltech/MSSS — PIA23898（キュリオシティ撮影のシャープ山） |
| 火星の物理量 | NASA/JPL Solar System Dynamics |
| 各探査機 | NASA science.nasa.gov / ESA / JAXA / ISRO / CNSA / UAE Space Agency |

画像はいずれも NASA・USGS の制作物でパブリックドメインです。
地図の配色はバイキング・オービターの観測に基づくもので、肉眼で見た色そのものではありません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体。地図も写真もデータも埋め込み済みの単一ファイル |
| `sw.js` | Service Worker。初回に本体を保存し、以後オフラインで動かす |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `icon-*.png` | ホーム画面アイコン（全球地図から正射投影で描いた火星） |

## 更新するとき

新しい `index.html` と `sw.js` を置き換えてください。`sw.js` の中の版名が変わることで
古い保存分が捨てられ、次に開いたときに新しい版へ自動で入れ替わります。
